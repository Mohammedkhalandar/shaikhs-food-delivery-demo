# Client demo handoff

Website: https://mohammedkhalandar.github.io/shaikhs-food-delivery-demo/

This is an intentionally fictional, static presentation. Kitchens, stock, prices, orders, delivery and cash reconciliation are simulations in your browser. There is no real login, payment, message, delivery request or database connection. Do not enter real customer, address or payment information.

## Two-minute walkthrough

1. Open the welcome disclosure. Explore Meadow Table, a clearly labelled fictional kitchen. Search for paneer, try category filters and Clear filters. An empty match has an explicit recovery message.
2. Clear filters, add an illustrative dish and open Basket. Try quantity controls and the stock limit. The simulated total includes a fictional delivery charge; no money is collected. Close with the button or Escape.
3. Select Simulate COD order. In Preview role choose Restaurant: simulate acceptance, preparation and ready for pickup. Choose Rider: simulate pickup and delivery. Choose Admin: simulate COD reconciliation. The order remains explicitly SIMULATED throughout.
4. Reset demo, or reload, to discard all in-memory state and try again. State is not saved across devices or reloads. This is not the original production application's persistence or authentication model.

## Evidence and limits

Automated checks use Chromium mobile/tablet/desktop emulation at 360, 390, 430, 768 and 1440 CSS pixels. Physical phones and third-party messaging-app preview rendering are not claimed verified. Canonical/Open Graph metadata and its original illustration are provided for sharing, but platforms may cache or crop previews. Performance measurements are reproducible laboratory samples, not representative real-user field statistics. GitHub Pages does not support this site's custom HTTP headers; HTML CSP blocks application connections/forms and the site has no real operations. No installable PWA, offline order queue, real tracking or account system is promised.
